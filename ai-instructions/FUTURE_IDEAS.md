# Future Ideas — Launchpad v2

Parking lot (plain markdown).

- One-time import of the old Launchpad electron-store registry.
- Global hotkey / OS-level quick capture (currently in-app only).
- Optional local-AI assist (Ollama): project summaries, "what's next", name suggestions.
- Mobile face: bind the service to the LAN with a simple token; a phone on Wi-Fi becomes another face.
- Packaged desktop installer (electron-builder) with a bundled Node so there's zero setup.
- Per-project colors/tags and grouping on the dashboard.
- Drag-to-reorder tasks; simple kanban columns for tasks if desired.
- `launchpad push` (optional) to send a captured note from the repo back into Launchpad.
- Activity timeline derived from git log across all projects ("what did I touch this week").

## Notes

### Launchpad owns the data — repo markdown is one-way `#5` 📌  [architecture]
Notes, ideas and tasks live in SQLite. `ai-instructions/LAUNCHPAD.md` is a generated mirror that is never read back, and agent writes go through the CLI/API. Treating markdown as the database is what killed v1: a regex parser silently dropped anything off-format.

### The server must run under system Node, never inside Electron `#4` 📌  [architecture]
Electron 33 bundles Node 20, which has no `node:sqlite`. Moving the database into the Electron process would reintroduce the native-module/node-gyp pain that killed earlier attempts. Electron is a window + tray that spawns the server as a child under system Node 24. Do not change this.

### Where the repo lives `#8`  [infra]
Repo: https://github.com/MikkelBlom/launchpad-v2 (private). Pushed over HTTPS via the gh credential helper — SSH auth is not available from the agent shell, so the remote is deliberately the https:// URL rather than git@github.com.

### Windows dev watch-out: orphaned server processes hold port 7420 `#6`  [desktop]
`tsx watch` leaves orphans on Windows, and the Electron shell does not respawn its server child after it exits. Kill by command line rather than by port:

Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*launchpad-v2*' }

If the desktop app shows a blank window, its server child is gone — restart the app.

### Where the written docs live `#7`  [docs]
ai-instructions/ holds the durable documentation: CLAUDE.md (invariants), WORKING_NOTES.md (decisions and their reasoning), FEATURES.md (what exists), ROADMAP.md, SESSIONS.md. These notes are the short version — the reasoning lives there.

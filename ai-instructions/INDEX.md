# ai-instructions/ — index

Working notes for AI agents on Launchpad v2. Unlike the original Launchpad, these are plain
human-readable markdown — Launchpad no longer parses them.

- **CLAUDE.md** — project identity, architecture, and invariants. Read first.
- **FEATURES.md** — what's done vs planned.
- **WORKING_NOTES.md** — key decisions and their reasoning (why node:sqlite, why separate server process, etc.).
- **SESSIONS.md** — chronological work log.
- **FUTURE_IDEAS.md** — parking lot.
- **LAUNCHPAD.md** — auto-generated by `launchpad pull` (one-way export from the Launchpad DB). Do not hand-edit.
